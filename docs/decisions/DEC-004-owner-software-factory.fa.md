# DEC-004 — CSEF به‌عنوان ابزار داخلی شرکت نرم‌افزاری شخصی

- تاریخ: ۲۰۲۶-۱۱-۱۷
- دامنه: فقط `ebrahimism/CSEF-Execution-Agent`
- تصمیم مالک: هدف CSEF فروش خود ابزار نیست؛ ایجاد توان ساخت نرم‌افزار واقعی از شرح‌حال ساده برای یک کسب‌وکار کم‌سرمایه است.
- اولویت‌ها: تکمیل درست نیازمندی‌ها، حفظ تصمیم‌ها، تقسیم وظیفهٔ قابل ردیابی، آزمون مستقل، امنیت، بازیابی و تحویل واقعی. کاهش هزینه مطلوب است ولی شرط لازم موفقیت نیست.
- اجرای تصمیم: [معماری](../architecture/OWNER-SOFTWARE-FACTORY-v1.fa.md) و [نقشهٔ راه](../roadmap/ACTIVE-EXECUTION-v1.fa.md).
- این فایل **صورت‌جلسهٔ مالک در مخزن** است، نه اصلاح بی‌صدای ProjectBook. `docs/PROJECT-GOALS.json` تاریخی دست‌نخورده است. هر ProjectBook عملی باید تغییر هدف را با مسیر `ProjectBook.amend` و نسخهٔ جدید ثبت کند؛ هیچ مدل یا سند خارجی حق تغییر هدف پذیرفته‌شده را ندارد.
- اجرای اولیه: افزودن validator ساختاریِ گراف وظایف به‌صورت ماژول جداگانه و بدون تغییر Gate یا پایگاه داده.
- محدودیت: validator تنها ساختار، وابستگی، پوشش شناسه‌های نیاز و مالکیت فایل را بررسی می‌کند؛ درستی معنایی، صحت پیاده‌سازی، امنیت sandbox یا پایان محصول را ثابت نمی‌کند.
