# شواهد S2 — ۲۰۲۶-۱۱-۱۷

**منبع:** مخزن \`ebrahimism/CSEF-Execution-Agent\`، شاخهٔ \`feat/s2-native-structured-providers-and-audit\`.

## پیاده‌سازی / Implementation

1. دو آداپتر موجود حفظ شدند و با فرمت native JSON Schema مطابق مسیر اختصاصی هر سرویس توسعه یافتند.
2. validation محلی نهایی برای schema کامل حفظ شد؛ قیود subset در سرور به دروغ تأیید نمی‌شوند.
3. مصرف و مشخصات مدل، فرمت، زمان و usage در رسید بدون کلید ضبط می‌شود. هزینهٔ دلاری فقط با نرخ دستی مدل خاص تخمین می‌شود؛ \`cost_usd\` همچنان نامعلوم است.
4. حد فراخوانی اتمیک و پایدار روی جدول \`changes\` پایگاه واحد پیاده شد؛ سقف تعداد فراخوانی، نه سقف تضمینی هزینهٔ دلار.
5. ابزار smoke test دوزبانهٔ سرویس‌ها امکان ساخت رسید خصوصی و تغییرناپذیر opt-in را دارد و نتیجهٔ ناقص را PASS نمی‌نامد.

## حدود پذیرش

تست‌های \`tests/providers/test_s2_controls.py\` و regression مخزن باید با GitHub CI پاس شوند. **تا پیش از اجرای owner-credentialed smoke، عبارت «اتصال واقعی دو API تأیید شد» نادرست است.**

عدم اجرا: هیچ کلید حقیقی در این PR/CI نیست، هیچ API پولی فراخوانی نشده، هیچ تغییر در Gate یا Docker/VM یا رابط کاربری نیست. انتقال data به ارائه‌دهنده فقط با اجرای آگاهانهٔ مالک.

**باقی‌مانده:** verified live receipts، تسویهٔ هزینهٔ کامل، health/circuit breaker و failover با سیاست مصوب؛ سنجش نهایی T013–T016 مشروط است و T017 Ollama اختیاری است.
